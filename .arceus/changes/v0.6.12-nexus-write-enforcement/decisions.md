# Decisions — v0.6.12

- **D1 橫幅看「範圍內增量」而不是只看累計值**。`blocked_requests_count` 是 instance 的終身計數器，
  只看它非零會永遠紅著。`blockedInRange`（查詢範圍內的增量 > 0）才代表「現在正在擋」。
  兩者都顯示：增量 0 但累計非零時給黃色並明講「可能限制仍在，只是這段期間沒人推」。
- **D2 三個計數器都存**。`blocked` 與 `grace_throttled` 分別代表「硬擋」與「寬限期降速」，
  是判斷還有沒有緩衝的唯一依據；只存一個就分不出來。
- **D3 計數器倒退（Nexus 重啟）時 `blockedInRange` 夾在 0**，不顯示負數。
- **D4 橫幅放在卡片最上方、在用量進度條之前**。這次的教訓就是進度條會給出錯誤結論，
  所以真正的答案要排在推論材料前面。
- **D5 欄位一律 nullable**，沿用 v0.6.11 的教訓：舊樣本沒有這些欄位，儲存層不能要求必填。
